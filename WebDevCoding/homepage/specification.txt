10 HTML Tags Used (besides <html>, <head>, <body>, <title>):
1. <header> - Page header with logo and navigation
2. <nav> - Navigation bar with links to all pages
3. <main> - Main content area for each page
4. <footer> - Page footer with copyright
5. <a> - Hyperlinks for navigation and buttons
6. <img> - Profile picture and hobby image
7. <div> - Generic container for layout and cards
8. <ul> / <li> - Unordered list for hobby items and contact info
9. <form> / <input> / <label> / <textarea> - Contact form
10. <button> - Dark mode toggle and project filter buttons

5 CSS Properties Used:
1. font-family - Sets the body font to Segoe UI
2. background-color - Changes background for header, footer, cards, dark mode
3. color - Sets text color (black by default, light in dark mode)
4. display - Uses flexbox for header, nav, and footer layout
5. text-align - Centers text for introduction, title, and project heading

JavaScript:
I used JavaScript to implement a dark mode toggle that switches between light and dark themes by toggling a CSS class on the body, and to dynamically filter and render a project grid by category on the projects page.

Bootstrap:
I used Bootstrap's card components for content layout, button classes for styling interactive elements, badge components for technology tags, form components for the contact page, and responsive grid classes to ensure the site looks good on both mobile and desktop.
